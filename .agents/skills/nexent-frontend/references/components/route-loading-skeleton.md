# Route loading skeleton

`components/common/RouteLoadingSkeleton.tsx` is the shared route fallback. Pass a localized destination pathname during sidebar transitions; without it the component uses the current pathname. Route families select cards, table, configuration, split-list or conversation placeholders. Unknown routes, including `/users`, use generic table placeholders including a title placeholder, without invented visible text or an invented accessible destination name.

The entire page, including its title, uses inert shimmer placeholders. Keep the translated destination heading in an `sr-only` span for assistive technology; do not display title text during loading. Title placeholders are 180px wide (at most 65%) and 28px high. All tabs, action buttons, labels, inputs and data are placeholders. Expose `common.loading` through the status accessible name, not visible body copy. Use Ant Design theme tokens for color and a 1.6-second left-to-right shimmer; disable animation for reduced motion. Shared geometry uses `p-6` (`p-4` on narrow screens), 32px field placeholders and responsive grids.

ClientLayout owns sidebar navigation transitions. SideNavigation calls its optional `onNavigate` only after existing login checks; other callers preserve direct router behavior. RouteTransitionContent keeps the source children mounted but hidden and inert, covers only content, and removes its cover when the React route transition settles. It must not reset a draft, disable the sidebar, bypass authorization, fake request failure based on elapsed time, or show a success screen. App Router `loading.tsx` provides a fallback for other entry points. This contract concerns route-resource waiting; feature data loaders retain their own lifecycle.

SideNavigation forwards the same optional `onNavigate` to AvatarDropdown. Normal profile-link activation closes the menu and starts the shared transition. Keep its locale-aware real href, disabled prefetch, and native behavior for modified clicks; callers without the callback retain ordinary Link navigation.
