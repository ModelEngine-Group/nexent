# Shared model selector

Workbench and current Agent chat (`/newchat`) use `ModelSelector` through the shared Composer. Model selection, deep thinking, effort and budget retain their existing callbacks and assistant-ui model context registration.

Both entry points derive available effort/budget controls from the selected model's supported capability, independent of saved/current thinking enablement. The switch controls activation only. Missing, unknown or unsupported effort capability must not fabricate generic levels. Preserve valid Agent/model/session defaults; resolve stale selections against supported values. Forward all existing ReasoningEffort IDs through callbacks and run configuration without aliasing high to xhigh. Automatic retains provider-default behavior and disabled thinking omits active reasoning overrides. Workbench's root generation configuration remains authoritative over ordinary-chat model context.

Use the shared Radix Select for effort options. Its SelectContent portal prevents clipping by the model popover; mark it with data-model-effort-popup so the model popover outside-interaction guard recognizes it as well as the advanced parameter panel. Keep the disabled empty state when no supported effort controls exist.

Use w-fit on the effort trigger so its width is just the selected text, chevron and standard padding/gap. Give the dropdown at least min-w-32 and preserve item pr-8 for the right-hand checkmark. Do not replace reserved indicator space with symmetric padding. End-align the nested effort dropdown and the convenience model panel so selection-label length does not shift their anchors; retain Radix collision handling and the compound Content's explicit alignment API.

`ModelSelector` renders Advanced settings below effort by default. Omit `parameterSettings` for local override state isolated by `parameterSettingsScopeKey` and the selected model during this component's lifetime. Composer supplies the active thread scope and running/disabled guard. Controlled callers retain `value`, `defaultValue`, `onChange` and `scopeKey` ownership; Workbench keeps its existing parent state. Compound consumers can render `ModelSelector.AdvancedSettings` inside `ModelSelector.Content`.

Opening the model menu or focusing Advanced settings must not open its nested panel. This includes automatic focus when preceding reasoning controls are disabled. Hover, an explicit click, Enter, Space or ArrowRight opens the panel; preserve Escape and outside dismissal and keep inputs usable while editing.

Reuse `ModelParameterSettings` for temperature 0–2 and top_p 0–1 with synchronized decimal sliders, numeric fields, keyboard interaction and restoring defaults. `value` contains runtime overrides; `defaultValue` contains the reset override state (normally empty). `inheritedValue` is display-only metadata from the selected ModelOption.defaultSampling: per-field Agent overrides followed by model defaults in Agent scope; tenant scope ignores Agent values. The API's read-only effective_sampling supplies the final shared SDK fallback (temperature 1.0, top_p 1.0). Null continues inheritance and zero stays explicit. Never hardcode SDK defaults in the frontend or fill raw model configuration from this metadata. Show effective numbers, including zero and off-grid decimals, at exact slider positions; marks preserve that position while interactive steps remain 0.1. A missing metadata response retains the unknown state rather than inventing a provider value. Input focus/blur alone must not create an override. Disable editing while running, when the caller is disabled or when no matching model is selected.

Only explicit sampling overrides enter model context and run generation_config; Workbench persists its canonical overrides. Displayed inherited defaults never become explicit payload values or global model writes. Restore defaults clears overrides and displays the current inherited metadata. Preserve all existing reasoning and model selection callbacks. The legacy `/chat` route was removed on develop; current chat uses `/newchat`.

Restoring sampling defaults is an explicit non-submit action. Discard an uncommitted numeric draft instead of committing it on pointer-induced blur before reset. For persisted conversations, retain the existing configuration save/version guard and pending lock while preserving the document, active thread, message DOM/state and composer draft. Shared message renderer component types must remain stable when read-only, Agent or callback props update; pass current render props through the message context rather than constructing new component functions during each settings save.
