# MCP tool group

ToolDrawer owns filtered service groups, service pagination, eligible tool IDs, local draft selection and batch parameter loading. McpToolGroup owns expansion only and renders existing ResourceItem children through a callback. Expanding never selects tools; the independent labelled checkbox reflects eligible or already-selected matching children, including mixed state. Batch loading disables group/page checkboxes and confirmation. Required parameters remain configurable individually; batch selection skips tools requiring configuration and duplicate names. Failed lookups leave the batch unchanged and allow retry. Closing invalidates pending batch work.

Search matches service metadata and tool metadata, while tag predicates still intersect tool IDs. A group action affects matching children; the MCP header selects the current service page. Other sources keep flat pagination/selection. Missing service metadata uses usage as the name; no visibility rule is relaxed. Service description and tags come from the existing MCP list endpoint. UI labels use toolPool translations. Checkbox and expansion controls are separate keyboard targets with aria-checked/aria-expanded/aria-controls. The optional ResourceDrawer selectAllLabel preserves the default label for existing callers.
