# Input

## Behavior

Use Ant Design `Input` and preserve its behavior and configuration.

## Style

- Height: `28px`.
- Border radius: `4px`.
- Use the default border.

Tailwind CSS:

```text
h-7 rounded-[4px] border border-solid border-[#c9c9c9]
```

Use the native component with the central theme:

```tsx
import { Input } from "antd";
```
