智能代码审查官

域0 代码与研发 零配置 · 可直接创建

智能代码审查官是一个开箱即用的代码质量守护 Agent。它读取你的项目源码，自动执行 AST 语法分析、ESLint 规则检查和团队红线规则扫描，最终输出结构化的审查报告。

该方案预置了通用的代码审查最佳实践规则集，无需任何额外配置即可创建 Agent 实例。创建后你只需将项目路径或 Git 仓库地址发给 Agent，它会在每次代码变更时自动审查并反馈结果。

审查报告支持 Markdown、JSON、HTML 三种输出格式，可直接集成到 CI/CD 流水线或 PR Review 流程中。
