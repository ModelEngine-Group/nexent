# 智能体列表页高保真实现基准（2026-10-08）

来源：共享软件中「智能体创建_列表卡片」页面的标注面板。以下尺寸均为设计稿原始像素，而非共享画面的 69% 缩放值。该文档用于本次前端实现与验收；未标注的内容保留原有行为，不自行补充字体族或新的业务数据。

## 页面骨架

- 设计画板 1920×1080；左侧导航 64px；右侧内容区 1856px，白色背景，四周内边距 24px。
- 页标题行宽 1808px、高 48px，上下内边距 10px，标题沿用现有页面文字和默认标题字体，不设置 `font-family`。
- 引导区域沿用现有可展开/收起逻辑；设计稿展开状态宽 1808px、高 378px，与标题下方间距 12px。桌面实测高度和标签栏位置均与此值一致。
- 列表标签栏位于引导区域下方，宽 1808px、高 32px，两个标签间距 32px，底边 1px `#DFDFDF`；选中项 `#0067D1`，未选中项 `#777777`。
- 列表区随容器宽度伸缩，不把画板固定高度作为页面最小高度。

## 工具栏、卡片、分页

- 工具栏宽度占满，高 32px；左侧搜索框 360×32px；右侧新建按钮与视图切换，两者间距 8px；主按钮高 32px。导入是原有功能，需保留可访问入口。
- 卡片网格在设计宽度为四列，列间距 16px、行间距 12px；卡片宽度由容器等分，高 148px。工具栏到卡片间距 12px，卡片到分页间距 12px。
- 卡片白色背景，1px `rgba(201,201,201,0.4)` 边框，12px 圆角，左右内边距 24px、上下 16px。标题区头像 40×40px，与文字间距 12px；标题 16px/24px、字重 500、字距 0、`#191919`。类型标签高 22px、左右 8px、上下 2px、4px 圆角、1px `#B3B3B3` 边框、`rgba(25,25,25,0.05)` 背景。描述占满卡片内部宽度，最多两行，字号 12px、行高 20px、字距 0、`#777777`。
- 底部日期/状态行高 18px、字号 12px、字距 0；日期颜色 `rgba(25,25,25,0.7)`。更新日期只显示有依据的数据，使用 `YYYY-MM-DD`。未提供更新时间时不得把创建时间谎称更新时间。
- 卡片悬浮态使用蓝色描边，出现「配置」「发布」按钮；右上角更多菜单及其复制、版本、导出、删除等原有动作保留。
- 分页行宽度占满、高 32px，左侧总数，右侧每页数量、页码和跳页。默认每页 10 条；分页与服务端实际总数联动。

## 行为边界和验收

- 搜索、创建、导入、卡片详情、配置、更多菜单、分页、引导展开/收起继续可用。
- 视图切换仅改变卡片排布，不改变卡片内容或服务器数据。
- 响应式列数可随视口下降，但设计宽度下应为四列。
- 列表接口当前没有「导入来源」字段，不能仅凭展示文案伪造“导入的智能体”分组；该标签暂不启用，数据行为待确认。
- 悬浮态「发布」入口进入现有配置页并请求打开原有发布弹窗；发布前继续执行该页的表单与保存校验，不直接从列表创建版本。
- 比对高保真时检查画板宽度下的区域位置、卡片内部文字与间距，并运行相关前端测试、类型检查和构建。

## 表格列表模式（当前“列表状态”设计稿）

- 仅实现现有视图切换中的表格形态；页面标题、引导区、标签栏以及网格卡片形态保持现状。
- 表格模式的操作区宽 1807px、高 32px；搜索框固定 296×32px。操作区与表格主体垂直间距 12px。
- 表格主体宽 1807px；高度自适应填充列表可用空间，最大 500px，不能固定为 200px。数据超出主体可用高度时仅主体内部滚动。主体之后间隔 12px 显示分页行，分页行高 32px。设计稿当前视窗展示表头和 4 条智能体记录；行数以实际数据为准。
- 列顺序：名称、类型、描述、状态、创建人、更新时间、操作。创建时间列按用户要求改为更新时间；不得从 `create_time` 回填。
- 当前设计稿可见名称、类型、描述、上线状态、创建人、更新时间，以及配置/发布/删除操作。截断长描述以避免侵入相邻列。现有创建、导入、搜索、详情、配置、发布、删除/更多操作和服务端分页行为继续保留。
- 设计稿没有明确标注各列精确宽度、单元格边距或表格文字字号/颜色。实现时不把截图推算值伪装成标注值；沿用项目 UI 基础规范及现有可复用组件样式，在 1807px 设计宽度下按列内容比例伸缩，并在窄视口保留表格内横向滚动。
- 表格主体高度根据表头和当前行数自适应，最高 500px；较小视口下按列表剩余空间收缩，超出主体可用高度时由主体内部滚动。数据较少时不撑满未使用空间。
- 类型字段取智能体现有标签；创建人只显示接口已有 `author`，没有值时显示占位符。更新时间只显示有效的 `update_time`，缺失或非法时显示占位符。

## 表格组件与样式约束

- 列表表格以及后续通用数据表格都使用 Ant Design `Table`，并通过可复用的 `StandardTable` 组件应用统一样式；不新增原生 HTML 表格实现。
- 表格默认字色 `#191919`、字号 `14px`、字间距 `0px`；背景为白色，表头使用 `#f3f3f3`。
- 设计稿主体标注高度为 200px，当前画面展示一个表头和四条记录，对应行高 40px。智能体表格沿用 40px 行高；列表可用区域仍按上文要求自适应，最大 500px，不能固定为 200px。
- 表格正文行使用 Ant Design 分隔线 `#f0f0f0`；表头列之间使用 `1px solid #c9c9c9` 竖线，高 `14px` 并垂直居中，最后一列右侧不加线；不增加正文竖线或表格外边框。狭窄的类型和更新时间表头左右内边距为 `8px`，完整展示文字与筛选图标。
- 列宽未在标注面板中逐列标出，继续按现有列内容比例自适应；筛选图标、行操作、更新时间字段和分页行为保持原有逻辑。
- 表格模式不得把智能体标为知识库；不改动列表上方的介绍和引导文案。
