### 设计有但 AC 无（仅关注点）
- 权限种子机制：通过版本化迁移为持 conversation/chat 相关角色补 /conversation-manage（不含 SU）
- 向后兼容：不传筛选参数时行为与现状一致
- 错误处理：沿用现有 401/500 错误码约定
- 日志记录：后端查询日志包含筛选参数与分桶口径

### 风险/边界
- RISK-2：全表 ilike 扫描性能风险（当前阶段数据量小，量大时考虑 pg_trgm）
- RISK-5：现有消费方兼容性（新增参数全可选，默认不传保持原行为）

所属模块: 对话管理/列表筛选
测试标题: 验证日期范围筛选功能（含端点）
前置条件:
  1. 登录具备【对话管理】权限的账号
  2. 造数：对话A（创建时间 1758360000000）、对话B（创建时间 1758446400000）、对话C（创建时间 1758532800000）

  3. 点击筛选按钮，等待列表刷新
  4. 核对返回的对话列表

预期结果:
  1. 进入对话管理页，列表显示所有对话
  2. 日期范围筛选生效，仅显示创建时间在选定区间内的对话（对话A）
  3. 列表刷新成功，分桶计数随筛选更新

测试标题: 验证无筛选参数返回所有对话（向后兼容）
请求方式: GET
前置条件:
  1. 测试账号已认证且具有对话管理权限
  2. 服务正常运行

请求参数:
  {
    "today_start_ms": 1758360000000,
    "week_start_ms": 1757740800000
  }

预期状态码: 200
预期业务码: 0

预期响应体:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "conversation_id": 123,
        "conversation_title": "示例对话",
        "agent_id": 42,
        "chat_mode": "execution",
        "create_time": 1758360000000,
        "update_time": 1758360000000
      }
    ],
    "metadata": {
      "total": 1,
      "today": 1,
      "last_7_days": 0,
      "older": 0
    }
  }
}
```

校验点:
  - code = 0，表示业务成功
  - message = "success"
  - data.items 为数组类型，包含所有对话
  - data.metadata.total 与 items.length 一致
  - metadata 分桶计数正确（无筛选时保持现状口径）
  - 返回字段与现有契约一致，无缺失无多余
