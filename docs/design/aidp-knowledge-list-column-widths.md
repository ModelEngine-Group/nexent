# AIDP 知识库列表列宽规则

更新日期：2026-10-09。

本次只调整 AIDP 知识库列表的表格模式。知识库详情内的文件、上传任务表格已交接给其他开发人员，不在本次修改范围内。卡片模式和 ES 知识库不变。

## 拖动列宽

- 在相邻表头之间放置拖动区域，鼠标悬浮显示左右调整光标和分隔线。
- 向右拖动：左列增加，右列减少；向左拖动：左列减少，右列增加。
- 每次只调整分界线两侧的两列，其他列保持宽度，表格总宽不变。
- 所有列最小宽度为 64px。任意一侧到达下限后停止移动，不继续挤压第三列。
- 最后一列右边没有相邻列，不提供拖动区域。操作列可以通过它左侧的分界线调整。
- 隐藏列不参与分配，拖动影响的是当前可见的相邻列。
- 拖动期间不选中文字，不触发行点击；松开、取消或离开页面时恢复光标。
- 拖动区域支持键盘聚焦，左右方向键每次移动 8px，同样遵守最小宽度。

示例：名称 240px、类型 120px，分界线向右移动 40px 后分别为 280px、80px。继续向右时，类型最多缩至 64px，名称最多增至 296px。

## 容器宽度变化

- 按表格容器实际宽度计算，包含窗口变化和侧栏展开、收起。
- 使用用户调整后的比例重新分配可用宽度。
- 按比例计算不足 64px 的列固定为 64px，剩余空间按其他列的比例分配。
- 容器小于可见列数乘以 64px 时，保留最小宽度并提供横向滚动。
- 名称固定在左侧、操作固定在右侧。
- 隐藏、恢复列时保留对应的宽度偏好。当前偏好保存在组件内存中，刷新页面恢复默认比例。

## 内容与操作

- 表头和文字单元格保持单行，超出显示省略号；鼠标悬浮显示完整内容。
- 权限列空间足够时保留现有标签，空间不足时使用可省略的文字摘要；悬浮展示权限和有权查看的用户组名称。
- 操作列小于 144px 时使用三个点菜单，保留导入文件、删除及现有权限限制；宽度足够时保留文字按钮。

本规则取代知识库列表旧方案中“只改变当前列、其他列不变、拖动使表格总宽变化”的说明。详情页列宽规则需由接手同事单独确认，不随本次改动改变。
