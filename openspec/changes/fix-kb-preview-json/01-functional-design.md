# 知识库预览体验修复 - 功能设计

## 预览与删除操作

- “预览”使用中性或主题色，hover 时使用主题强调色。
- “删除”继续使用红色危险色。
- 两个操作必须使用独立的样式常量，避免后续新增操作复用危险色。

## JSON 文件预览

1. 用户在知识库文件列表点击 JSON 文件的“预览”。
2. 前端根据 `.json` 扩展名识别为文本类型，并请求现有预览接口。
3. 后端确认对象存在且未超过预览大小限制后，将 `application/json` 视为可直接预览类型。
4. 后端返回原对象名、`application/json` 内容类型和文件大小。
5. 前端按照文本分块逻辑读取并展示 JSON 原文。

## 异常行为

- 对象不存在或超过大小限制时，沿用现有 404/413 行为。
- 不支持的文件类型继续返回现有不支持类型错误。
- JSON 内容即使格式不完整，也按原始文本展示；解析入库不属于本次预览逻辑。

## 兼容性

- 不新增 API 路径，不改变预览接口的返回结构。
- 不改变 XML 的预览行为。
- 不改变 HTML 的现有展示行为；本次仅允许 JSON 进入已有文本分支。
