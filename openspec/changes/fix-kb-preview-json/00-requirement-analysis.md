# 知识库预览体验修复 - 需求分析

## 问题陈述

知识库文件列表中的“预览”和“删除”操作共用红色文字样式，预览操作被误呈现为危险操作。与此同时，前端已识别 `.json` 文件为文本，但后端预览类型白名单没有允许 `application/json`，导致 JSON 文件无法打开预览。

## 目标

- 将预览操作调整为中性/主题色，将危险红色仅用于删除操作。
- 允许知识库中的 JSON 文件通过现有文本流预览链路直接查看。
- 保持现有 PDF、图片、Markdown、CSV、纯文本和 Office 预览行为不变。

## 非目标

- 本次不增加 XML、YAML 或其他新格式的预览支持。
- 本次不修改知识库文件删除、上传日期、解析错误持久化或 MinIO 清理逻辑。
- 本次不改变 HTML 预览的渲染策略。

## 影响与风险

- 前端影响知识库文档列表中的两个操作按钮样式。
- 后端影响预览文件类型判断；JSON 将作为原始文本返回，不执行 JSON 内容。
- 不涉及数据库迁移、存储对象写入或权限模型变更。

## 验收标准

[ ] 文档列表中的“预览”按钮不再使用红色危险色，“删除”按钮仍使用红色危险色。
[ ] 已存在的 JSON 文件可以打开预览并显示原始文本内容。
[ ] JSON 文件走文本分块请求，不触发 Office 转 PDF 或不支持类型错误。
[ ] PDF、图片、Markdown、CSV、纯文本和 Office 文件的原有预览测试继续通过。
[ ] XML 文件的行为保持不变，仍不在本次支持范围内。
