# 导出与发布指南

Nexent 平台不仅支持接入外部资源，也支持将平台开发的资源（Agent 智能体）导出或发布给外部系统使用，实现平台能力的延伸与扩展。通过导出与发布，Nexent 可以无缝嵌入企业的整体 IT 架构，与各类业务系统协同工作。

## 📋 总览

Nexent 提供以下几种导出与发布方式：

| 资源类型 | 方式 | 说明 | 适用场景 |
|----------|------|------|----------|
| **Agent** | 导出配置文件 | 导出 JSON/ZIP 格式的 Agent 配置 | 迁移 Agent 到其他 Nexent 环境 |
| **Agent** | 普通发布 | 发布后提供北向 RESTful API | 与业务系统深度集成，实现工作流自动化 |
| **Agent** | 发布为 A2A Agent | 将 Agent 暴露为 A2A 服务 | 跨平台 Agent 协作、支持 A2A 协议的外部系统调用 |

### 生态互联

通过 A2A 协议和北向 API，Nexent 可以与外部系统深度集成：

- **企业集成**：与 ERP、CRM 等业务系统对接
- **工作流自动化**：将 Agent 能力嵌入自动化流程
- **多 Agent 协作**：与其他平台的 Agent 协同工作

## 🔄 流程概览

### Agent 智能体导出流程

```
1. 选择 Agent ──► 2. 导出配置文件 ──► 3. 导入到其他 Nexent 部署
```

支持 JSON 和 ZIP 两种格式。ZIP 格式包含完整的配置和资源文件，适合完整迁移。详细步骤请参阅 [Agent 智能体导出](./agents-export)。

### Agent 普通发布流程

```
1. 发布 Agent 版本 ──► 2. 生成 API Key ──► 3. 调用北向 API ──► 4. 与业务系统集成
```

北向 API 提供完整的会话管理能力，支持流式响应和附件上传。详细步骤请参阅 [Agent 智能体发布](./agents-publish) 与 [调用 Agent 北向 API](./northbound-api)。

### Agent 发布为 A2A 流程

```
1. 发布 Agent 版本 ──► 2. 勾选「发布为 A2A Agent」──► 3. 获取调用信息 ──► 4. 外部系统调用
```

发布后，Agent 会生成符合 A2A 1.0 规范的 Agent Card，外部系统可以发现并调用。详细步骤请参阅 [Agent 智能体发布](./agents-publish)。

## ⚖️ 能力对比

| 方式 | 交互方式 | 实时性 | 协议 | 适用场景 |
|------|----------|--------|------|----------|
| **导出配置文件** | 离线 | 无 | — | 迁移、备份 |
| **普通发布（北向 API）** | 在线 | 实时/流式 | RESTful API | 业务系统集成 |
| **A2A 发布** | 在线 | 实时 | A2A 1.0（REST + JSON-RPC） | 跨平台 Agent 协作 |

## 🔒 安全考虑

在导出或发布资源时，请注意以下安全事项：

| 考虑项 | 说明 | 建议 |
|--------|------|------|
| **敏感信息** | 导出的配置可能包含 API Key 等敏感信息 | 使用前检查并适当处理 |
| **访问控制** | 暴露的 API 需要认证保护 | 仅授权可信系统访问 |
| **数据安全** | 外部调用可能访问敏感数据 | 设置适当的数据权限策略 |
| **审计追踪** | 记录 API 调用日志便于审计 | 启用日志记录和监控 |
