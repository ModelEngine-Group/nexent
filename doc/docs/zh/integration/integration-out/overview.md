# 导出与发布指南概述

Nexent 平台不仅支持接入外部资源，也支持将平台开发的资源（Skill 技能、Agent 智能体）导出或发布给外部系统使用，实现平台能力的延伸与扩展。通过导出与发布，Nexent 可以无缝嵌入企业的整体 IT 架构，与各类业务系统协同工作。

## 导出与发布能力总览

Nexent 提供以下几种导出与发布方式：

| 资源类型 | 方式 | 说明 | 适用场景 |
|----------|------|------|----------|
| **Skill** | 导出 ZIP 包 | 将技能打包为可分发文件 | 分享到其他 Nexent 部署或第三方平台 |
| **Agent** | 导出配置文件 | 导出 JSON/ZIP 格式的 Agent 配置 | 迁移 Agent 到其他 Nexent 环境 |
| **Agent** | 发布为 A2A Agent | 将 Agent 暴露为 A2A 服务 | 供外部系统通过 A2A 协议调用 |
| **Agent** | 开放北向 RESTful API | 提供 HTTP API 接口 | 与业务系统深度集成，实现工作流自动化 |

## 为什么需要导出与发布能力？

### 资产复用与迁移

通过导出功能，您可以将一个 Nexent 部署中开发的 Agent 和 Skill 迁移到另一个部署，实现跨环境的资产复用。这对于以下场景特别有价值：

- **多环境部署**：开发环境 → 测试环境 → 生产环境的平滑迁移
- **多租户分发**：将成熟的 Agent 分发给不同租户使用
- **备份恢复**：定期导出配置作为备份

### 生态互联

通过 A2A 协议和北向 API，Nexent 可以与外部系统深度集成：

- **企业集成**：与 ERP、CRM 等业务系统对接
- **工作流自动化**：将 Agent 能力嵌入自动化流程
- **多 Agent 协作**：与其他平台的 Agent 协同工作

## 能力对比

| 方式 | 交互方式 | 实时性 | 适用场景 |
|------|----------|--------|----------|
| **导出配置文件** | 离线 | 无 | 迁移、备份 |
| **A2A 协议** | 在线 | 实时 | 跨平台 Agent 协作 |
| **北向 API** | 在线 | 实时/流式 | 业务系统集成 |

## 安全考虑

在导出或发布资源时，请注意以下安全事项：

| 考虑项 | 说明 | 建议 |
|--------|------|------|
| **敏感信息** | 导出的配置可能包含 API Key 等敏感信息 | 使用前检查并适当处理 |
| **访问控制** | 暴露的 API 需要认证保护 | 仅授权可信系统访问 |
| **数据安全** | 外部调用可能访问敏感数据 | 设置适当的数据权限策略 |
| **审计追踪** | 记录 API 调用日志便于审计 | 启用日志记录和监控 |
