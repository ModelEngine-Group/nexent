# Skill 技能导出

Nexent 支持将平台开发的 Skill 导出为标准化的 ZIP 包，便于分享到其他 Nexent 部署，或供其他支持 Skill 格式的平台使用。

## 导出功能说明

导出功能可以将技能打包为可分发的文件，包含：

- `SKILL.md`：技能定义文件
- `config/`：参数配置文件（如有）
- `scripts/`：配套脚本（如有）
- `assets/`：静态资源（如有）

## 操作步骤

### 从 Skill 仓库导出

1. 进入 **Skill 仓库** → **我的 Skill** 页面
2. 找到需要导出的技能
3. 点击技能卡片上的「更多」按钮
4. 选择「导出」
5. 系统生成 ZIP 文件并自动下载

### 导出的文件结构

导出的 ZIP 包遵循标准 Skill 包结构：

```
skill-name/
├── SKILL.md              # 技能定义（必需）
├── config/
│   ├── config.yaml       # 参数默认值
│   └── schema.yaml       # 参数类型定义
├── scripts/
│   └── *.py              # Python 脚本
├── examples.md           # 使用示例
└── assets/               # 静态资源
```

## SKILL.md 格式说明

导出的 `SKILL.md` 包含 YAML Front Matter 和正文内容：

```yaml
---
name: csv-analyzer
description: |
  分析 CSV 文件并生成数据质量报告。适用于用户上传 CSV 文件后的数据检查场景。
tags:
  - data-analysis
  - csv
---

# CSV 数据质量报告

## 功能说明

此技能用于分析 CSV 文件的数据质量...

## 使用示例

当用户提供 CSV 文件时...
```

## 跨平台使用导出的 Skill

### 在其他 Nexent 部署导入

1. 在目标 Nexent 部署中，进入 **Skill 仓库** → **我的 Skill**
2. 点击「创建 Skill」
3. 选择「上传技能文件」
4. 上传导出的 ZIP 包
5. 系统解析并展示技能信息
6. 确认后点击「创建」

详细步骤请参阅 [Skill 接入](../integration-in/skills)。

### 在第三方平台使用

导出的 Skill 包符合标准化格式，理论上可被任何支持相同格式的平台导入使用。

**检查清单**：
- [ ] ZIP 包包含 `SKILL.md`
- [ ] YAML Front Matter 包含 `name` 和 `description`
- [ ] 文件编码为 UTF-8
- [ ] 脚本路径使用正斜杠 `/`

## 敏感信息处理

导出的 Skill 包可能包含以下敏感信息，请在使用前检查：

| 内容类型 | 风险 | 处理建议 |
|----------|------|----------|
| API Key | 泄露认证凭证 | 导出前移除或替换为占位符 |
| 内部路径 | 信息泄露 | 使用通用路径替代 |
| 自定义脚本 | 业务逻辑泄露 | 根据需要决定是否导出 |

### 清理敏感信息

1. 在导出前，打开 `SKILL.md` 检查内容
2. 检查 `config/config.yaml` 中的配置
3. 检查 `scripts/` 中的脚本代码
4. 如有敏感信息，手动编辑后重新导出

## 版本管理

Skill 支持版本管理，导出时默认导出当前版本。

### 查看历史版本

1. 在技能详情页面，点击「版本历史」
2. 查看各版本的修改时间和内容
3. 选择特定版本导出

### 版本兼容

导出的 Skill 包可以在以下版本的 Nexent 中导入：
- 当前版本
- 高于当前版本的兼容版本

## 权限控制

### 导出权限

- **创建者**：可以导出自己创建的技能
- **有编辑权限的用户**：可以导出有编辑权限的技能
- **管理员**：可以导出所有技能

### 导入权限

导入的技能默认属于导入者，需要单独配置分享权限才能共享给其他用户。

## 常见问题

### Q: 导出的 ZIP 包无法导入其他平台

1. 确认 ZIP 包包含 `SKILL.md` 且位于根目录
2. 检查 YAML Front Matter 格式是否正确
3. 确认文件编码为 UTF-8
4. 检查是否有特殊字符导致解析失败

### Q: 导出的技能参数配置丢失

参数配置存储在 `config/schema.yaml` 和 `config/config.yaml` 中。确认这些文件存在且格式正确。

### Q: 导出的脚本无法执行

1. 检查脚本路径是否正确
2. 确认脚本依赖是否完整
3. 验证脚本语法

### Q: 如何分享技能给同租户成员？

除了导出再导入外，您还可以：

1. 在技能详情页面点击「申请上架」
2. 管理员审核通过后，技能将在仓库中可见
3. 其他成员可以从仓库复制使用
