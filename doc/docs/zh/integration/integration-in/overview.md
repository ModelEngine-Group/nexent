# 接入指南概述

接入能力是 Nexent 平台开放生态的重要组成部分。通过接入外部 AI 资源，平台能够充分利用外部的工具、技能与智能体，让您的智能体拥有更强大的功能和更广泛的应用场景。

## 接入能力总览

Nexent 支持三种主要类型的资源接入：

| 资源类型 | 说明 | 接入方式 | 典型来源 |
|----------|------|----------|----------|
| **MCP 服务** | Model Context Protocol 工具服务 | URL 链接、容器配置、API 转 MCP | ModelScope、第三方自建 |
| **Skill 技能** | 打包的工作流和能力单元 | 上传 ZIP/MD 文件 | 社区分享、自定义开发 |
| **Agent 智能体** | 符合 A2A 协议的第三方 Agent | URL 发现、Nacos 发现 | 企业内部系统、第三方平台 |

## 为什么需要接入外部资源？

### 扩展智能体能力边界

通过接入外部 MCP 服务，您的智能体可以调用各种专业工具，如 GitHub 代码管理、数据库查询、文件处理等，无需从头开发这些功能。

### 复用已有投资

如果您的组织已经在其他地方开发了 MCP 服务或 Skill 包，可以直接接入到 Nexent 平台使用，保护已有的技术投资。

### 融入更大生态

通过 A2A 协议接入第三方 Agent，您的智能体可以与其他平台的 Agent 协作，形成更强大的多 Agent 工作流。

## 安全考虑

在接入外部资源时，请注意以下安全事项：

| 考虑项 | 说明 | 建议 |
|--------|------|------|
| **认证信息** | 外部服务可能需要 API Key 或 Token | 使用平台的密钥管理功能，避免明文存储 |
| **网络连通性** | 确保平台能够访问外部服务 | 检查防火墙配置和安全策略 |
| **数据权限** | 接入的服务可能访问敏感数据 | 评估服务权限，仅授予必要访问 |
| **来源可信度** | 确保接入的服务来源可靠 | 优先使用官方认证或社区验证的服务 |
