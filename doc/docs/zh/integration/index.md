# 第三方集成

本文档面向第三方开发者、合作伙伴和客户，帮助您了解如何与 Nexent 平台进行深度整合。无论您是想将已有的 AI 资源（MCP 服务、Skill 技能、Agent 智能体）纳入 Nexent 平台管理和使用，还是希望将 Nexent 平台的能力集成到您自己的业务系统中，本文档都将提供详尽的指导。

Nexent 平台提供了双向资源整合能力：
- **接入**：将外部 AI 资源引入 Nexent 平台，让平台智能体可以调用这些资源
- **导出**：将 Nexent 平台的能力输出给外部系统使用

## 接入能力概览

Nexent 支持接入以下三类外部资源：

| 资源类型 | 接入方式 | 适用场景 |
|----------|----------|----------|
| **MCP 服务** | 远程链接、容器部署、API 转 MCP | 接入 ModelScope 等第三方 MCP 市场服务，或将企业自有 REST API 转换为 MCP 工具 |
| **Skill 技能** | 上传 Skill 包（ZIP/MD） | 导入社区分享的技能包，或使用 NL2Skill 自然语言生成技能 |
| **Agent 智能体** | A2A 协议发现 | 通过 URL 或 Nacos 发现第三方 Agent，实现跨平台协作 |

## 导出与发布能力概览

Nexent 支持以下几种导出与发布方式：

| 资源类型 | 导出方式 | 适用场景 |
|----------|----------|----------|
| **Skill 技能** | 导出为 ZIP 包 | 将平台开发的技能分享到其他 Nexent 部署或第三方平台 |
| **Agent 智能体** | 导出为 JSON/ZIP | 将智能体配置迁移到其他 Nexent 环境部署，实现跨环境复用 |
| **Agent 智能体** | 发布为 A2A Agent | 将智能体暴露给外部系统调用，支持 REST 和 JSON-RPC 协议 |
| **Agent 智能体** | 开放北向 RESTful API | 通过标准化 API 与外部业务系统集成，实现工作流自动化 |

## 快速开始

### 想要接入外部资源？

1. **MCP 服务**：前往 [MCP 服务接入指南](./integration-in/mcp)，了解如何快速接入 ModelScope 等第三方 MCP 市场服务
2. **Skill 技能**：前往 [Skill 技能接入指南](./integration-in/skills)，学习如何上传和管理技能包
3. **Agent 智能体**：前往 [Agent 智能体接入指南](./integration-in/agents)，使用 A2A 协议发现并协作外部 Agent

### 想要将平台能力导出？

1. **导出 Skill**：前往 [Skill 技能导出指南](./integration-out/skills)，将技能打包分享
2. **导出 Agent**：前往 [Agent 智能体导出指南](./integration-out/agents)，迁移智能体配置
3. **调用 Agent 北向 API**：前往 [ Agent 北向 API](./integration-out/northbound-api)，与业务系统深度集成
