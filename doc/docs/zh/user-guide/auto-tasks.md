# 自动任务

自动任务可以让智能体按照指定的时间或周期，自动在绑定的会话中执行一条指令。例如，您可以让智能体每天早上汇总信息、每隔一段时间检查数据，或在指定时间完成一次性任务。

自动任务由会话创建，并且始终绑定创建它的会话和智能体。任务创建后，系统会在计划时间启动智能体，执行结果和错误信息会保存在运行历史中。

## 使用前准备

创建自动任务前，请先完成以下准备：

1. **配置可用的模型**：确保租户中已配置能够执行对话的语言模型。
2. **准备智能体**：在 [智能体开发](./agent-development) 中创建并保存智能体。
3. **配置任务所需能力**：如果指令需要知识库、工具、Skill、记忆或其他智能体，请先在智能体配置中完成对应设置。
4. **确认会话可用**：自动任务会复用绑定会话的上下文，创建任务的用户需要能够访问该会话。

如果智能体缺少任务所需的能力，系统会先提示您完成配置，任务不会被创建。

## 创建自动任务

### 通过会话创建

自动任务目前通过对话页面创建。打开一个已经选择智能体的会话，在输入框中描述需要自动执行的工作，并同时说明执行时间或周期。

建议在指令中包含以下信息：

- **要执行的工作**：例如“整理今天新增的知识库文档并输出摘要”。
- **执行时间**：一次性任务需要指定未来的日期和时间。
- **执行周期**：周期任务需要说明间隔或固定时间，例如“每 6 小时执行一次”或“每天上午 9 点执行”。
- **时区**：如果执行时间不是当前浏览器时区，请明确指定时区。

例如：

```text
每天上午 9 点，使用当前智能体整理昨天新增的项目文档，输出一份简短摘要并列出需要关注的问题。
```

系统会识别消息中的自动任务意图，并生成任务提案。提案中通常包含任务标题、执行指令、使用的智能体、执行计划和能力检查结果。

### 检查并确认提案

提交消息后，请在对话中的自动任务卡片中检查：

- **任务标题**：用于在自动任务列表中识别任务。
- **任务内容**：智能体每次运行时实际执行的指令。
- **智能体**：执行该任务的智能体及其当前配置。
- **执行计划**：首次执行时间、重复规则和时区。
- **能力检查结果**：任务所需的工具、知识库、Skill、记忆等能力是否可用。

确认信息无误后，点击 **创建任务**。如果需要调整标题、任务内容或执行计划，点击 **修改**，保存修改后再创建。

如果能力检查未通过，点击 **配置智能体**，完成智能体配置后返回会话重新创建任务。一个会话只能绑定一个有效的自动任务；如果当前会话已经绑定任务，需要先管理或删除原有任务。

## 设置执行计划

自动任务支持一次性执行和周期性执行两种方式。

### 一次性执行

一次性任务只执行一次。选择 **单次执行**，设置一个未来的首次执行时间即可。

一次性任务成功、失败或被取消后不会再次生成计划。执行完成后，任务状态会变为 **已完成**。

### 周期性执行

周期性任务会按照规则重复执行。选择 **重复执行** 后，还需要选择一种周期规则：

- **固定间隔**：按照间隔秒数重复执行。例如，间隔设置为 `21600` 秒表示每 6 小时执行一次。
- **Cron 表达式**：按照五字段 Cron 表达式执行。字段顺序为“分钟 小时 日 月 星期”。

常用 Cron 示例：

| 需求 | Cron 表达式 |
|------|-------------|
| 每天 9:00 执行 | `0 9 * * *` |
| 每个工作日 18:30 执行 | `30 18 * * 1-5` |
| 每小时的第 0 分钟执行 | `0 * * * *` |
| 每月 1 日 9:00 执行 | `0 9 1 * *` |

Cron 表达式使用任务设置的时区计算。系统会校验表达式格式；无效表达式无法保存。

### 时间和时区

创建或编辑任务时，系统会记录首次执行时间和时区。管理页面默认使用浏览器时区，您也可以在对话提案中明确指定其他 IANA 时区，例如 `Asia/Shanghai` 或 `UTC`。

请注意：

- 一次性任务的执行时间必须晚于当前时间。
- 周期任务从首次执行时间开始计算。
- 如果设置了结束时间，超过结束时间后不会继续生成新的执行记录。
- 固定间隔不能小于系统配置的最小间隔，默认最小值为 5 秒；部署者可以通过环境变量调整该值。

## 管理自动任务

打开用户指南中的 **自动任务** 页面，可以查看当前用户创建的任务。列表支持按任务名称、智能体名称和状态筛选，也可以查看任务的执行计划、下次执行时间和最近一次结果。

### 编辑任务

在任务的更多操作中点击 **编辑**，可以修改：

- 任务名称
- 执行指令
- 任务类型
- 首次执行时间
- 周期规则、固定间隔或 Cron 表达式
- 单次运行超时时间

修改执行指令后，系统会重新检查智能体所需的能力。若检查不通过，修改不会生效。

单次运行超时时间以秒为单位，默认值为 1800 秒（30 分钟），页面允许设置的最小值为 60 秒。超时后当前运行会被终止，并记录为 **已超时**。

### 立即运行

点击任务操作中的运行按钮，可以不等待计划时间，立即启动一次运行。立即运行属于手动触发，不会消耗周期任务的计划次数，也不会改变周期任务的下次执行时间。

如果绑定会话已有正在运行的智能体任务，新的运行会被跳过，并在运行历史中记录为 **已跳过**。同一会话不会并行执行多个自动任务运行。

### 暂停和恢复

- **暂停**：暂停后，任务不会按计划触发，但已开始的运行不会因此自动删除。
- **恢复**：恢复任务后，系统会根据当前时间和原执行计划计算下一次执行时间。
- **系统暂停**：周期任务连续失败或超时达到 5 次时，系统会自动暂停任务，以避免持续产生无效运行。修复智能体配置或任务指令后，可以点击 **恢复**。

一次性任务完成后没有可用的未来执行时间，不能通过恢复操作重新执行；如需再次执行，请创建新的任务或通过绑定会话手动发起请求。

### 查看运行历史

点击任务操作中的 **执行历史**，可以查看该任务的运行记录，包括：

- 运行状态
- 触发方式（手动或计划触发）
- 计划执行时间
- 错误信息

处于 **排队中** 或 **运行中** 的记录可以点击 **取消**。已经结束的记录可以删除；删除运行记录不会删除自动任务本身。

### 删除任务

在任务的更多操作中点击 **删除** 并确认后，任务将不再自动执行，绑定的会话不会被删除。正在运行的任务会同时请求停止当前智能体运行，并取消对应的活动运行记录。

## 状态说明

| 状态 | 说明 |
|------|------|
| 已启用 | 任务已创建，等待下一次计划执行 |
| 运行中 | 当前有一次运行正在执行 |
| 已暂停 | 用户主动暂停了任务 |
| 系统暂停 | 系统因连续失败或超时自动暂停了任务 |
| 已完成 | 一次性任务已结束，或周期任务已经达到结束条件 |
| 草稿 | 任务尚未完成创建流程，通常不会出现在可执行任务中 |

运行记录的状态包括 **排队中**、**运行中**、**成功**、**失败**、**已跳过**、**已取消** 和 **已超时**。

## 执行机制与注意事项

- 后端服务启动时会启动自动任务调度器；如果部署配置将 `AGENT_AUTOMATION_ENABLED` 设为关闭，任务不会被调度执行。
- 调度器会周期性查找到期任务，并为任务申请租约后执行。在多副本部署中，同一计划不会因为多个服务副本同时运行而重复领取。
- 周期任务默认采用“错过则跳过”策略。服务重启期间错过的周期不会补跑，而是计算下一次未来执行时间。
- 任务执行时会重新校验已绑定的能力。如果工具、知识库或其他依赖已被删除或不可用，本次运行会失败。
- 任务会保存创建时的智能体运行快照，用于保留模型、工具参数和原始指令等运行上下文；编辑任务指令后，系统会更新相关能力绑定。
- 任务执行结果会写入绑定会话，因此可以直接打开任务对应的会话查看上下文和输出。

## 常见问题

### 为什么提交消息后没有生成自动任务？

请检查消息是否同时包含明确的业务指令和执行时间或周期。仅描述“帮我定期关注”但没有具体执行内容或时间，系统无法生成可执行的任务计划。

### 为什么任务无法创建？

常见原因包括：执行时间已过去、Cron 表达式无效、固定间隔小于系统允许的最小值、智能体缺少必需能力，或当前会话已经绑定其他自动任务。

### 任务为什么变成系统暂停？

周期任务连续失败或超时达到 5 次后会被系统暂停。请先查看执行历史中的错误信息，修复智能体、模型、工具或任务指令，再点击 **恢复**。

### 删除任务会删除对话吗？

不会。删除自动任务只会停止后续自动执行，并保留绑定的会话及其历史消息。
