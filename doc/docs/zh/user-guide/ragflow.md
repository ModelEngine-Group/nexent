# RAGFlow 知识库对接

Nexent 支持通过 `ragflow_search` 工具检索 RAGFlow 平台的知识库（Datasets）：智能体根据查询词在选定的 RAGFlow 知识库中搜索，返回最相关的结果。

## 前置条件

- 可访问的 RAGFlow 服务（如 `http://<host>:9380`）
- 在 RAGFlow 平台创建的 API Key
- RAGFlow 平台上已创建并包含文档的知识库

## 配置步骤

1. 进入「智能体配置」页面，打开目标智能体
2. 在工具管理中将 **ragflow_search**（本地工具）添加到智能体
3. 点击该工具行的 **配置** 按钮，在配置参数中填写：

| 参数 | 说明 |
| --- | --- |
| **server_url** | RAGFlow API 基础 URL，如 `http://<host>:9380` |
| **api_key** | RAGFlow API 密钥（以密码框显示） |
| **dataset_ids** | 点击选择框，从同步的列表中勾选要检索的 RAGFlow 知识库（可多选） |
| **top_k** | 返回给 LLM 的搜索结果最大数量，默认 3（1–100） |
| **similarity_threshold** | 结果的最小相似度阈值，默认 0.2（0–1） |
| **vector_similarity_weight** | 混合搜索中向量相似度的权重，默认 0.3（0.0–1.0） |
| **keyword** | 是否在混合搜索中启用关键词搜索，默认关闭 |
| **highlight** | 是否在搜索结果中启用高亮，默认开启 |

4. 点击 **保存配置**。未选择知识库时无法保存

打开知识库选择框时会自动同步一次 RAGFlow 知识库列表；也可以在列表弹窗中点击 **同步** 手动刷新。列表显示每个知识库的描述、文档数与分块数；没有文档的知识库不可选择。

## 运行参数

智能体运行时，LLM 可提供：

- **query**：搜索查询词
- **doc_id**（可选）：限定搜索到特定文档，可传单个文档 ID 或 JSON 数组
- **dataset_ids**（可选）：临时覆盖本次搜索的知识库范围

## 注意事项

- 鉴权使用 RAGFlow API Key（Bearer 方式）；鉴权失败时会在同步与检索时报错
- 单次检索会对所有选定知识库执行一次合并搜索，结果按相似度降序返回
- 无结果时工具会提示放宽或缩短查询词
