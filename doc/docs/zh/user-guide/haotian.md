# 昊天 Haotian 知识库对接

Nexent 支持通过 `haotian_search` 工具检索昊天（Haotian）外部知识库：智能体根据查询词在选定的知识集/知识库中检索，返回最相关的结果。检索请求由 Nexent 后端代理转发，前端不直接调用外部服务。

## 前置条件

- 可访问的昊天知识集列表 URL 与检索 API URL
- 有效的 Authorization 凭证（如 `Bearer xxx`）
- 目标知识集下已创建知识库

## 配置步骤

1. 进入「智能体配置」页面，打开目标智能体
2. 在工具管理中将 **haotian_search**（本地工具）添加到智能体
3. 点击该工具行的 **配置** 按钮，在配置参数中填写：

| 参数 | 说明 |
| --- | --- |
| **list_url** | 昊天知识集/知识库列表 URL |
| **retrieve_url** | 昊天检索 API URL |
| **authorization** | Authorization 请求头（如 `Bearer xxx`，以密码框显示） |
| **dataset_ids** | 点击选择框，从同步的列表中勾选要检索的知识库（可多选） |
| **top_k** | 返回结果最大数量，默认 3（1–100） |
| **reranking_enable** | 是否启用检索接口内置重排，默认关闭；开启后可配置重排策略与模型 |
| **keyword_weight / vector_weight** | 关键词与向量相似度权重，默认 0.1 / 0.3（0–1） |
| **score_threshold_enabled / score_threshold** | 是否启用结果过滤阈值及阈值取值（0–1） |

4. 点击 **保存配置**。未选择知识库时无法保存

昊天使用专用知识库选择弹窗，按「知识集 → 知识库」两级展示：每个知识集一张卡片，卡片内勾选具体知识库；顶部支持按知识集名/知识库名搜索。

## 运行参数

智能体运行时，LLM 只需提供：

- **query**：搜索查询词

## 注意事项

- **仅支持关键词检索**（keyword_search）：昊天检索接口不支持语义搜索与混合搜索，请保持默认搜索方法
- 列表 URL、检索 URL、Authorization 三项均为必填
- 检索走昊天接口的内置重排参数，而不是 Nexent 本地重排模型
