# 官方技能

Nexent 内置了一组可直接安装的官方技能，安装后即可在智能体的技能配置中启用对应能力，并按需填写技能参数。

## 技能列表

### 文档生成

| 技能名称                          | 能力说明                                     |
| --------------------------------- | -------------------------------------------- |
| `docx`                            | 创建、读取、编辑 Word 文档，支持修订与格式保留 |
| [`create-docx`](./create-docx.md) | 根据结构化内容规范生成 Word 文档并返回可下载的文件产物 |
| `pdf`                             | 读取、生成、合并与拆分 PDF 文件               |
| `pptx`                            | 创建与编辑 PowerPoint 演示文稿                |
| `xlsx`                            | 创建与编辑 Excel 表格，支持公式与数据分析     |
| `create-excel`                    | 根据结构化内容规范生成 Excel 工作簿           |

### 设计与前端

| 技能名称                  | 能力说明                                             |
| ------------------------- | ---------------------------------------------------- |
| `canvas-design`           | 基于设计理念生成 PNG/PDF 视觉作品                     |
| `frontend-design`         | 构建或改造界面时的差异化视觉设计指南                |
| `web-artifacts-builder`   | 使用现代前端技术构建复杂的多组件 Web 页面             |
| `slack-gif-creator`       | 创建适配 Slack 的动画 GIF                             |

### 搜索与检索

| 技能名称                 | 能力说明                                                       |
| ------------------------ | -------------------------------------------------------------- |
| `search-knowledge-base`  | 搜索 Nexent 本地知识库，支持混合、精确和语义模式               |
| `search-dify`            | 搜索 Dify 知识库，支持关键词、语义、全文和混合模式             |
| `search-datamate`        | 搜索 DataMate 知识库，支持相似度阈值控制                       |
| `search-idata`           | 搜索 iData 知识库                                              |
| `search-web-tavily`      | 使用 Tavily 进行公网实时搜索                                   |
| `search-web-linkup`      | 使用 Linkup 进行图文混合搜索                                   |
| `search-web-exa`         | 使用 Exa 进行深度网页搜索                                      |

### 多模态分析

| 技能名称            | 能力说明                               |
| ------------------- | -------------------------------------- |
| `analyze-image`     | 基于视觉语言模型分析图片内容并进行问答 |
| `analyze-text-file` | 提取并分析 PDF、Word、Excel 等文件内容 |

### 通信与终端

| 技能名称        | 能力说明                                                     |
| --------------- | ------------------------------------------------------------ |
| `email-utils`   | 通过 IMAP 收取邮件、通过 SMTP 发送邮件，支持 HTML、CC 和 BCC |
| `run-shell-ssh` | 通过 SSH 在远程终端执行 shell 命令，支持会话管理             |

### 开发工具

| 技能名称        | 能力说明                                             |
| --------------- | ---------------------------------------------------- |
| `mcp-builder`   | 创建高质量 MCP 服务器，让 LLM 与外部系统集成         |
| `skill-creator` | 创建新技能、改进现有技能并测量技能表现               |

## 安装与使用

1. 超级管理员或租户管理员进入 **资源管理** 页面，打开「Skills」页签。
2. 点击 **安装官方技能**，在弹窗中查看当前可安装的官方技能及其状态（已安装的技能会标注）。
3. 选择需要的技能并完成安装。
4. 在智能体配置的技能列表中启用已安装技能。
5. 根据技能要求填写参数并保存配置。

> 💡 创建新租户时，系统会自动为租户安装官方技能，无需手动操作。

官方技能的具体参数和调用约束以对应技能包中的 `SKILL.md` 为准。

## 自定义文件生成 Skill

如需基于官方 `create-docx` 扩展 Word 文档能力，或开发用于生成 Markdown、PDF、表格、演示文稿等文件的自定义 Skill，请参阅[自定义文件生成 Skill 指南](./custom-file-generation-skill.md)。
