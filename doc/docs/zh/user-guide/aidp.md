# AIDP 知识库对接

Nexent 支持对接 AIDP 企业知识检索平台，提供向量、全文、图谱三种检索通道及其组合。AIDP 有两种接入形态：

- **平台托管形态**：通过部署开关 `ENABLE_AIDP_KNOWLEDGE` 开启，「知识库配置」页面整体切换为 AIDP 知识库管理，检索工具由系统自动注入，普通用户无感使用
- **独立部署形态**：面向独立部署的 AIDP 服务，通过 `ind_aidp_search` 工具手动配置连接，不影响平台其他知识库功能

## 1. 平台托管形态

### 1.1 前置条件

托管形态由部署侧配置，界面无录入入口：

| 环境变量 | 说明 |
| --- | --- |
| `ENABLE_AIDP_KNOWLEDGE` | 设为 `true` 开启 AIDP 知识库（默认关闭） |
| `AIDP_SERVER_URL` | AIDP 服务地址 |
| `AIDP_API_KEY` | AIDP API 密钥（由后端持有，前端不接触密钥） |
| `AIDP_TENANT_ID` | AIDP 租户 ID，默认 `aidp` |

### 1.2 开启后的界面变化

- **「知识库配置」页面**：整体切换为 AIDP 知识库管理（侧边栏菜单名称不变）
- **「资源管理」页面**：租户资源的「知识库」页签隐藏，知识库统一在「知识库配置」页管理
- **智能体对话**：会话「当前对话知识库」切换为 AIDP 知识库页签，单次最多选择 10 个知识库
- **智能体评估**：AI 生成评测集的「关联知识库」下拉切换为 AIDP 知识库

### 1.3 知识库管理

**知识库列表**：支持按名称搜索（服务端过滤）、表格/卡片两种视图、表头自定义与列宽调整；每行显示权限范围（私有 / 用户组只读 / 用户组可编辑）、创建人与创建时间，提供「导入文件」「删除」操作；删除前会预览受影响的智能体。

**新建知识库**：表单分为基础信息、文档切片、向量生成、检索匹配、知识图谱、权限与用户组六个分区，默认已填充推荐配置（切片 512 token、重叠 10%、检索 TopK 10 等），可按需调整：

- 文档切片：智能分片 / 法律条文两种模式，可设置切片最长 token 与重叠百分比
- 向量生成：选择向量化模型（无可用模型时无法创建）
- 检索匹配：相似度阈值与向量检索 TopK
- 知识图谱：可选开启，支持领域选择（常规/金融/医疗/法律法规）、子图扩展跳数、构图模型与提示词语言等；**图谱关闭后无法再次开启**
- 权限与用户组：普通用户创建的知识库固定为私有；其他角色可选私有 / 用户组只读 / 用户组可编辑，并选择授权用户组

**文件管理**：知识库详情页提供「已上传文件 / 上传任务 / 详细信息」三个页签：

- 支持上传文本、网页、文档、表格、图片等格式；单次最多 50 个文件，文本与表格类不超过 20 MB，其他类型不超过 1024 MB
- 文件状态包括已入库、删除中、删除失败；批量删除单次最多 10 个
- 上传任务保留近 30 天记录，可查看失败原因并重新提取
- 详细信息页可修改切片、检索与图谱配置（图谱关闭为永久操作），以及编辑名称、描述与权限

### 1.4 权限说明

- **创建者**：对自己的知识库拥有一切权限
- **私有知识库**：仅创建者可见（包括管理角色在内）
- **普通用户**：只能看到自己创建的知识库
- **开发者**：可查看所在授权用户组的共享知识库，权限按组内设置（只读或可编辑）
- **管理角色**（超级管理员、管理员、资产管理员）：可查看并编辑全部共享知识库
- 上传、删除文件、修改配置与删除知识库均需要可编辑权限

### 1.5 在智能体与对话中使用

- 开启托管形态后，知识检索工具 `aidp_search` 由系统自动注入受管智能体，**不会出现在工具池中**，也无需手动配置连接
- 检索范围遵循双重约束：智能体配置的知识库 ∩ 当前用户有权限的知识库；用户在会话「当前对话知识库」中指定的知识库同样受权限约束
- 运行参数：LLM 只需提供 **query**（搜索词）与可选的 **kds_list**（临时指定知识库列表，最多 10 个）

## 2. 独立部署形态（ind_aidp）

独立形态适用于直接对接独立部署的 AIDP 服务，不影响本地知识库等功能。该工具独立持有连接配置，不参与托管形态的权限体系与会话知识范围。

### 2.1 配置步骤

1. 进入「智能体配置」页面，打开目标智能体
2. 在工具管理中将 **ind_aidp_search**（本地工具）添加到智能体
3. 点击该工具行的 **配置** 按钮，在配置参数中填写：

| 参数 | 说明 |
| --- | --- |
| **server_url** | AIDP 服务地址（必须为 http/https 地址，不支持携带账号密码） |
| **api_key** | AIDP API 密钥（以密码框显示） |
| **tenant_id** | AIDP 租户 ID，默认 `aidp` |
| **kds_list** | 点击选择框，从同步的列表中勾选要检索的知识库（最多 10 个） |

4. 如需调整检索行为，展开 **检索配置参数** 区块自定义（见下节）；默认显示「默认配置」，修改后显示「已自定义」，可点击「恢复默认」还原
5. 点击 **保存配置**

### 2.2 检索配置参数

| 参数组 | 参数 |
| --- | --- |
| **检索方式** | 向量检索 / 全文检索 / 图谱检索，可组合（默认三通道全开） |
| **返回控制** | 返回条数上限 top_k（默认 10，1–100）；结果过滤阈值 score_threshold（0–1） |
| **结果重排** | reranking_enable（默认开启）；重排策略：性能优先（默认）/ 精度优先 / 术语覆盖优先 |
| **检索细节** | 向量候选数、全文候选数（1–500）；各通道过滤阈值（0–1）；各通道返回上限（0–100，不超过 top_k）；图谱参与重排 |
| **增强检索** | 查询改写、查询扩展、关联检索（默认关闭）；多模态检索（默认开启，可返回图片与表格块） |

知识库选择弹窗为服务端分页（每页 10 条），支持按名称、ID 或描述搜索当前页，多选上限 10 个；点击 **同步** 可重新拉取列表。

### 2.3 与托管形态的差异

| 对比项 | 平台托管 | 独立部署 |
| --- | --- | --- |
| 启用方式 | 部署开关，全员生效 | 智能体级别添加工具 |
| 连接配置 | 环境变量（后端持有） | 工具配置中填写 |
| 权限控制 | 远端目录 ∩ 用户权限，自动收缩 | 不参与平台权限，按配置的知识库检索 |
| 工具可见性 | 系统注入，不可手动选择 | 智能体工具池中手动添加 |
| 多模态结果 | 图片通过安全标记嵌入回答 | 图片经 Nexent 代理展示（密钥不下发浏览器） |

## 3. 运行参数

两种形态的运行参数一致：

- **query**：搜索查询词
- **kds_list**（可选）：本次调用的知识库 ID 列表；不传时使用工具配置中的知识库，最多 10 个
