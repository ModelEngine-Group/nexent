# Dify 知识库对接

Nexent 支持通过 `dify_search` 工具检索 Dify 平台的知识库（Datasets）：智能体根据查询词在选定的 Dify 知识库中搜索，返回最相关的结果并附带引用来源。

## 前置条件

- 可访问的 Dify 服务（如 `https://api.dify.ai/v1` 或自部署地址）
- 在 Dify 平台创建的 API Key（Datasets 访问权限）
- Dify 平台上已创建并包含文档的知识库

## 配置步骤

1. 进入「智能体配置」页面，打开目标智能体
2. 在工具管理中将 **dify_search**（本地工具）添加到智能体
3. 点击该工具行的 **配置** 按钮，在配置参数中填写：

| 参数 | 说明 |
| --- | --- |
| **server_url** | Dify API 基础 URL，如 `https://api.dify.ai/v1` |
| **api_key** | Dify API 密钥（以密码框显示） |
| **dataset_ids** | 点击选择框，从同步的列表中勾选要检索的 Dify 知识库（可多选） |
| **top_k** | 每个知识库返回的搜索结果最大数量，默认 3（1–100） |
| **search_method** | 搜索方法：关键词搜索、语义搜索（默认）、全文搜索、混合搜索 |
| **rerank** | 是否对搜索结果启用重排，默认关闭；开启后需选择重排模型 |

4. 点击 **保存配置**。未选择知识库时无法保存

打开知识库选择框时会自动同步一次 Dify 知识库列表；也可以在列表弹窗中点击 **同步** 手动刷新。列表显示每个知识库的文档数、分块数与创建时间；没有文档的知识库不可选择。

## 运行参数

智能体运行时，LLM 只需提供：

- **query**：搜索查询词

## 注意事项

- 鉴权使用 Dify API Key（Bearer 方式）；鉴权失败或限流时会在同步与检索时报错
- 检索按所选知识库逐个执行，并为结果附带原文引用链接
- 保存配置后对该智能体的所有调用生效；同一智能体可同时配置其他知识检索工具
