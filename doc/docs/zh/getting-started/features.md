# 核心特性

Nexent 将智能体的开发、运行和管理集中在同一平台。本页介绍 Nexent 的核心特性：如何把业务需求变成可用的智能体，如何为它接入模型、知识和工具，以及团队如何评估、发布并维护这些智能体。

## 🛠️ 智能体开发

### 对话式开发与优化

用 NL2Agent 描述智能体要解决的问题，不必先写出完整的配置。Nexent 会通过多轮对话澄清需求，查找已安装或可安装的工具与技能，协助安装和绑定资源，并生成核心提示词、开场白和示例问题。初稿生成后，可以继续在对话中修改，也可以手动调整配置；在线调试确认后即可发布。智能体也支持复制、导入和导出，便于在已有配置上继续开发。

### 提示词一键优化

如果现有提示词没有准确表达任务目标，可以让通过提示词一键优化能力让开发助手按诉求优化相关内容。先审阅建议，再决定是否替换原有提示词。

### 可视化调试与模型对比

- **跟踪一次测试**：输入测试问题后，可以边看流式回答，边查看执行步骤、所选工具及其输入和返回结果。调试可随时停止或清空。
- **比较两个模型**：让两个模型使用相同的提示词并排作答，比较它们对同一问题的表现，为发布时的模型选择提供参考。

## ⚙️ 智能体运行

### 多智能体协作与并行

主智能体可以把复杂任务拆成多路，例如分别查找资料和整理已有文档，再汇总各路结果。协作智能体可以继续向下委派，也可以并行工作；每个智能体可使用独立的模型、工具和运行策略，子任务结果也可单独查看。

### 多模态交互与文件交付

- **用适合任务的方式提供材料**：根据已配置的模型能力，可支持输入文本、图片、音频、视频或文档。配置语音识别或语音合成后，还可分别使用语音输入或回复播报。
- **在会话中交付成果**：智能体生成的文档、表格和图片等资源可在页面中直接预览或下载，不必离开会话另找文件。

### 定时任务

在对话中说明要做什么、何时执行，Nexent 会生成定时任务的草案；确认后即可创建绑定当前会话的一次性或周期性任务。计划有变时，可以立即运行、暂停、恢复或编辑任务，也可以通过执行历史核对以往的运行情况。

### 技能按需加载

智能体先读取技能摘要，只有任务确实需要该技能时，才加载完整的 `SKILL.md`、引用文件或脚本。这种渐进式披露方式让无关的技能内容不必占用当前会话的上下文。开发时，NL2Agent 也可按需求推荐、安装和绑定技能。

### 隔离沙箱

模型生成的代码和技能脚本在独立的沙箱环境中执行，与平台主服务及业务数据分离。需要执行脚本来处理文件或生成成果时，无须在平台主服务中直接运行这些代码。

### 安全护栏

可按需为智能体启用护栏，按规则拦截不安全的工具或模型调用。配置时，可以先用自然语言描述要拦截的内容，生成候选规则，再用样本文本预览哪些规则会命中。

## 🚀 智能体管理

### 版本管理

智能体配置采用草稿和发布版本分离的方式管理。用户可以在草稿中持续编辑和调试，确认后再发布；历史版本可用于对比问答效果和回滚。导入、导出和复制功能便于跨环境复用配置。

### 业务集成与跨平台协作

通过 REST API 和受管理的 API 密钥，可将智能体会话等能力接入现有业务系统。如果需要与其他智能体平台协作，Nexent 支持通过 Agent-to-Agent（A2A）协议发布智能体，也可通过 Agent Card 地址或注册中心发现并调用外部智能体。

### 智能体评估

根据业务场景描述或现有用例文件建立评测集，再由一个或多个评估器批量评分。团队可以用汇总结果判断是否达到上线标准，也可以查看单条用例的得分和失败原因，找出下一轮需要改进的问题。评估报告可导出，便于团队复核。

## 🧩 AI 资产管理

### 开放模型接入

Nexent 支持接入兼容 OpenAI API 的模型服务，也可从 ModelEngine 同步模型。语言、向量、重排、图像理解与生成、视频和音频理解、语音识别与合成等模型可集中管理。绑定模型前，可以检查服务是否连通，并按用途配置模型能力。

### 多方知识来源

智能体可按任务选择一种或多种知识来源：

- **本地知识库**：将文本、PDF、Office 文档、CSV、JSON 或 EPUB 等资料上传到个人或组内共享知识库。平台自动解析、分块和向量化文档，支持语义或混合检索，也可查看摘要和维护文档分片。
- **第三方知识库**：接入 Dify、AIDP 等三方知识库，让智能体检索已有知识作为回答依据，不必重复构建知识库。
- **互联网检索**：通过 Exa、Linkup 或 DeepSeek 等互联网检索服务查找网页信息，补充内部资料未覆盖的内容。

回答附带引用信息，可以打开命中的文档片段或网页核对依据，也可在原文件可用时下载查看。

### 分层记忆机制

Nexent 按信息的使用范围管理记忆：

- **租户记忆**：用于保存同一租户内可复用的长期信息。
- **用户记忆**：记录当前用户的长期偏好和背景。
- **智能体记忆**：保留当前用户与特定智能体交互产生的短期信息。

系统可以从对话中提取关键信息，并在后续任务中检索相关记忆。除了查看和维护记忆，也可通过 Dreaming 将短期信息整理为带版本的长期记忆。

### MCP 工具接入

Nexent 使用模型上下文协议（MCP）将外部服务接入智能体：

- **接入工具**：连接远程 MCP 服务、以容器部署服务，或通过 OpenAPI 将现有 REST 接口转换成 MCP 工具。
- **验证可用性**：检查服务连通性、查看容器启动日志或刷新工具列表，绑定前可测试工具的参数和返回结果。

### 技能创建

用户可将Skill.md文档或者.zip技能压缩包上传到系统中，也可用 NL2Skill 描述希望智能体掌握的工作方法，自动生成技能包，同时支持通过自然语言优化现有技能。

### 资产仓库

仓库集中管理可共享的智能体、MCP 服务和 Skill。开发者可以申请上架资源，管理员负责审核；租户内用户可以浏览、安装或复制已上架资源。安装或复制智能体时，系统会检查模型、工具和 Skill 冲突，并引导用户完成必要配置。

## 🔐 用户与资源权限

Nexent 提供多租户、分角色的权限管理体系：

- 五层角色：超级管理员、租户管理员、运维管理员、开发者、普通用户，职责分明
- 多租户隔离：租户间数据完全隔离，支持跨租户的平台级管理
- 用户组机制：通过用户组管理资源和访问权限，支持灵活的权限委托
- 邀请码机制：受控注册，保障平台安全性
- 资源级权限：智能体、知识库、模型、MCP 和 Skill 可按用户组授权，支持只读或编辑权限
- 接口访问管理：管理员可以管理租户用户的北向 API Key

## 📊 运维与可观测性

从了解整个平台的使用情况，到排查某一次智能体运行，Nexent 提供两种观察视角。

- **监控面板**：展示平台使用情况总览，包含指标如智能体数量、活跃用户数、智能体平均响应时延等。这些指标适合日常巡检，也能帮助判断问题是否值得进一步排查。
- **可观测中心**：详细展开智能体的一次运行轨迹。遇到回答异常或响应缓慢时，可以沿着运行轨迹查看调用了哪些工具、传入了什么参数、返回了什么结果，以及各次调用耗时。
