# 核心特性

Nexent v2.5.0 覆盖智能体生成、配置、调试、发布和运行，并提供模型、工具、知识、记忆与权限管理能力。

## ⚙️ 多模型集成

Nexent 可接入兼容 OpenAI API 的模型服务，也可从 ModelEngine 同步模型。平台统一管理 LLM、Embedding、Rerank、图片理解、图片生成、视频理解、音频理解、STT 和 TTS 等模型，并提供连通性检查和模型能力配置。

## 🤖 智能体零代码生成

用户可通过 NL2Agent 用自然语言描述目标。系统会通过多轮对话澄清需求，搜索已安装或可安装的工具与 Skill，协助完成资源安装和绑定，并生成职责提示词、使用要求、示例问题等配置。生成后可继续手动编辑、在线调试和优化，再发布为可用版本。智能体也支持复制、导入和导出。

## 🤝 A2A 协议与智能体协作

Nexent 支持 **Agent-to-Agent（A2A）** 协议。主智能体可以调用平台内的子智能体，也可以发现和调用外部 A2A 智能体。每个协作智能体可使用独立的模型、工具和运行策略，执行结果由主智能体统一整理后返回。

## 🧠 分层记忆机制

Nexent 提供三层记忆体系：

- **Tenant 记忆**：租户范围内可复用的长期信息
- **User 记忆**：当前用户的长期偏好和背景信息
- **Agent 记忆**：当前用户与特定智能体交互产生的短期记忆

智能体运行前会加载长期记忆，并检索与当前问题相关的 Agent 记忆。Dreaming 可手动执行或按计划运行，将稳定的短期记忆整理为带版本的长期记忆；管理员还可以查看筛选结果、切换历史版本或清空当前长期记忆。

## 📝 Skill 渐进式披露

Nexent 使用 **渐进式 Skill 披露**控制上下文规模：先加载简要信息，智能体确认需要某项能力后，再读取对应的 `SKILL.md`、引用文件或脚本。NL2Agent 也可以根据需求推荐、安装和绑定 Skill。Skill 脚本可在隔离沙箱中执行，降低对宿主环境的影响。

## 🗄️ 个人级知识库

用户可以创建个人或共享知识库。上传的文本、PDF、Word、PowerPoint、Excel、CSV、JSON、EPUB 等文件会经过解析、分块和向量化，再用于语义或混合检索。知识库支持摘要、分片管理和用户组授权；平台还会显示个人知识库用量，并按管理员设置的默认配额或用户配额限制上传。

## 🔧 MCP 工具生态系统

Nexent 基于 **Model Context Protocol（MCP）** 构建工具生态，让智能体通过统一协议调用外部服务。

- 支持远程链接、容器、OpenAPI 和本地镜像等接入方式
- 支持容器启动日志、连通性检查和工具列表刷新
- 支持将 MCP 服务发布到租户资源仓库，供其他用户安装
- 内置工具测试，可在绑定到智能体前验证参数和返回结果

## 🌐 互联网知识集成

Nexent 可接入多个网络搜索服务，也可检索 Nexent、Dify、RAGFlow、DataMate、AIDP 等知识源。智能体能够按任务选择公网信息或私有知识，并结合多个来源生成回答。

## 🔍 知识溯源与引用

知识库和搜索工具返回的结果可以附带引用。用户可在回答中查看引用标记，并在来源面板中打开对应文档或网页，核对回答依据。

## 🎭 多模态交互

问答界面支持文本、图像、音频、视频和文档输入。智能体可根据已配置的模型分析不同媒体，也可以在隔离工作区中生成文档、表格、图片等文件。生成文件会同步到对象存储，并以可预览或下载的形式显示在回答中。

## 🔢 智能体版本管理

智能体配置采用草稿和发布版本分离的方式管理。用户可以在草稿中持续编辑和调试，确认后再发布；历史版本可用于对比问答效果和回滚。导入、导出和复制功能便于跨环境复用配置。

## 🏪 智能体市场

资源仓库集中管理可共享的智能体、MCP 服务和 Skill。开发者可以申请上架资源，管理员负责审核；租户内用户可以浏览、安装或复制已上架资源。安装或复制智能体时，系统会检查模型、工具和 Skill 冲突，并引导用户完成必要配置。

## 👥 分权分域与用户管理

Nexent 提供多租户、分角色的权限管理体系：

- **四层角色**：超级管理员、租户管理员、开发者、普通用户，职责分明
- **多租户隔离**：租户间数据完全隔离，支持跨租户的平台级管理
- **用户组机制**：通过用户组管理资源和访问权限，支持灵活的权限委托
- **邀请码机制**：受控注册，保障平台安全性
- **资源级权限**：智能体、知识库、模型、MCP 和 Skill 可按用户组授权
- **接口访问管理**：管理员可以管理租户用户的北向 API Key
- **容量管理**：管理员可以查看个人知识库用量并设置默认或单独配额
