# Create an Evaluation Task

An evaluation task runs a selected agent version and scores its results with evaluators. Read the [Agent Evaluation overview](../evaluation) before creating a task.

## Select an evaluation mode

On the **Runs** tab, select **Create Evaluation** in the top-right corner. A drawer slides out with a mode switch at the top (default: **No Test Set**):

| Mode | Description |
|------|-------------|
| **Evaluation with a set** | Runs questions from an existing evaluation set; suitable for regression and release validation |
| **Evaluation without a set** | Has AI generate test questions from the agent configuration before running the agent; suitable for quick exploration |

## Create the task

1. In the left navigation, select **Agent Evaluation**, then open the **Runs** tab.
2. Select **Create Evaluation** in the top-right corner and choose an evaluation mode at the top of the drawer.
3. Under **Agent Configuration**, select the agent and version to evaluate. The version must be published; if no version is specified, the latest published version is used by default.
4. Under **Evaluation Configuration**, select a **Judge model**. With-set mode also requires an evaluation set (options show "name (case count)"); no-set mode requires a question count (1–50, 10 by default).
5. Under **Evaluators**, select 1–5 published evaluators. In no-set mode, evaluators that require a reference answer cannot be selected and are listed at the end.
6. In with-set mode, select **Trial Run** to verify the configuration first; then select **Start Evaluation**.

The task appears in the **Evaluation Tasks** list and runs in the background. It stores the agent version, Judge model, and evaluator configuration used at creation time; later edits do not change historical tasks.

## Evaluator inputs

The system prepares these standard inputs for evaluators:

| Field | Source |
|-------|--------|
| `query` | Evaluation-set `Question` / `query` |
| `expected` | Evaluation-set `Answer` / `answer`; empty in no-set mode |
| `actual` | Actual answer generated by the agent |
| `runtime_stats` | Runtime statistics from the agent execution |

Field mapping is filled in automatically when the task is created and requires no manual configuration. Use these field names when creating a custom evaluator.

## Trial Run

In with-set mode, the **Trial Run** button appears at the bottom of the creation drawer. It automatically uses the first case in the evaluation set as the test question, runs the agent, and shows the test question, agent output, and each evaluator's score in a dialog (green when the pass threshold is met, red otherwise). A trial run does not create an evaluation history record.

Start with a representative question to verify the agent version, Judge model, and evaluator configuration before running the full set.

## Task states and management

| State | Meaning |
|-------|---------|
| **Pending** | The task was created and is waiting for background execution |
| **Running** | The agent and evaluators are running |
| **Completed** | The task finished and results are available |
| **Failed** | The task or a key execution stage failed; use the error details to correct the configuration and create a new task |

The evaluation task list supports the following management actions:

- **Filter by agent**: the agent filter at the top of the list supports multiple selections; entering from the **Evaluate** menu on the Agent Configuration page applies that agent's filter automatically.
- **Column filters**: the evaluation-set and status columns support filtering by value.
- **Delete a task**: select the delete icon in the actions column and confirm. Deletion is available to the task creator and to super administrators, tenant administrators, and asset owners.
- The list shows 10 tasks per page, and running tasks refresh their status automatically.

For result details, see [View Results and Annotations](./results).
