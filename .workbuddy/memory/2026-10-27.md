## Actions 流水线分工梳理（19:25 用户询问）
- **实际只有 20 个 workflow 文件**（`git ls-tree origin/develop .github/workflows/`）。API 返回的 `automic-*`（拼写 automic）是**旧缓存/已删除文件**，实际文件名是 `auto-*`，查证时不能信 API 列表，要用 git。
- **构建（build）= 只在 runner 本地 `docker build`，产出 docker 镜像层，不登录 registry、不 push**。目的是**验证 Dockerfile 能编译通过、代码能打包**，属 PR 门禁。
  - `auto-build-main-dev.yml`（Docker Build Main Images）→ `docker build -t nexent/nexent:dev-amd64/-arm64`
  - `auto-build-web-dev.yml` / `auto-build-mcp-dev.yml` / `auto-build-terminal-dev.yml` / `auto-build-data-process-dev.yml`
  - 触发：`pull_request` + `push` 到 develop/release/**/hotfix/**，且带 `paths` 过滤（改了 backend/** 才跑 main/mcp/data-process，改了 frontend/** 才跑 web）
- **推包（push/发布）= 登录 registry + 多架构 buildx + `--push`**，产物对外可用。
  - `docker-build-push-mainland.yml`（→ 腾讯云 ccr.ccs.tencentyun.com/nexent-hub/*）
  - `docker-build-push-overseas.yml`（→ DockerHub）
  - 关键：`bash deploy/images/build.sh --platform linux/amd64,linux/arm64 --registry mainland --push`，7 个镜像 matrix（main/web/data-process/mcp/terminal/sandbox/sandbox-full）
  - **版本 tag 规则**（重要）：`workflow_dispatch` → 用 inputs.version；`refs/heads/main` → **固定 `latest`**；其他（tag push）→ 用 `ref_name`（即 v2.8.1）
  - 触发：push main + push tag `v*`（**同一操作会双触发**，且**无 concurrency 组**，这是 10-23 那天 8 条 run 互相抢 runner 的原因）
