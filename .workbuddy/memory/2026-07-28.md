## WorkBuddy 专家（Expert）概念拆解
- 用户问：WorkBuddy 专家是啥概念，是 agent+skill+内置工具的意思吗？
- 实际拆解 WorkBuddy 专家包目录结构（以 aihot 和 design-engine 为例）：
  - 专家 = 结构化角色包（Expert Package），不是简单 system prompt
  - 两种类型：Agent 型（单一角色）和 Team 型（主理人+N 个团员）
  - 专家包结构：plugin.json（元数据）+ agents/*.md（角色定义）+ skills/（附带 Skill）+ avatars/（头像）
  - **专家 = Agent + Skill + 头像 + 元数据**，没有 MCP 和 Recipe 变量
  - Agent MD 格式：frontmatter（name/description/maxTurns）+ markdown body（职责/SOP/团队协作铁律）
  - plugin.json 包含：expertType / teamInfo / displayName / categoryId / tags / quickPrompts / members
  - 关键差异：WorkBuddy 专家是"三维打包"（Agent+Skill+元数据），Nexent 方案是"四维打包"（Agent+Skill+MCP+IndustryRule+Recipe）
  - WorkBuddy 专家无 Recipe 变量、无 MCP 连接器、无 IndustryRule 独立层
  - 对应关系：WorkBuddy 专家 ≈ Nexent 方案（但 Nexent 多了 MCP+Recipe+IndustryRule 三个维度）
  - Team 型运行时：主理人执行 TeamCreate → 按 SOP 调度团员 → 成员回传 → 主理人汇编
  - 前端展示：tags 3 个 + quickPrompts 3 个 + defaultInitPrompt + 头像 + 行业分类（12 类 categoryId）
