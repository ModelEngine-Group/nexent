## 预览路由权限错误修复

**问题**：用户访问 `/zh/market-v2` 和 `/zh/agents/template/1` 时弹出"请切换有权限访问该页面的账号"权限错误

**根因**：`frontend/hooks/auth/useAuthorization.ts` 的 `isPreviewRoute` 正则写错
- `cleanPath = getEffectiveRoutePath(pathname)` 会去掉 locale 前缀（`/zh/market-v2` → `/market-v2`）
- 但正则写成 `/^\/[^/]+\/market-v2/` 要求两段路径，永远匹配不上单段的 `/market-v2`
- 导致 `isPreviewRoute` 始终为 false，路由守卫触发 `openAuthzPromptModal()` + `router.replace("/")`

**修复**：正则改为匹配去掉 locale 后的路径
```ts
const isPreviewRoute =
  /^\/market-v2(?:\/|$)/.test(cleanPath) ||
  /^\/agents\/template(?:\/|$)/.test(cleanPath);
```

**验证**：两个页面返回 HTTP 200，RSC payload 中的 `HTTPAccessErrorFallback` 是 Next.js 内置 not-found 边界的正常行为（首页也有），并非错误

**涉及文件**：
- `frontend/hooks/auth/useAuthorization.ts`（修复正则）
- `frontend/app/[locale]/layout.client.tsx`（已有预览路由绕过，用原始 pathname 匹配，正则正确）
