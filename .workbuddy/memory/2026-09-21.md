## hotfix/v2.6.1 → main round4（完成，含 #3988 HITL 大重构）
- 背景：#3990(28d0ebd57) 后又合入 #3988（3f467e3a9，refactor: remove human interaction features，110 文件 +2483/-9499，20:13 squash 合入 hotfix），main 落后 hotfix 一个提交；直接 PR 报 27 个冲突（含 10 个 modify/delete）
- 环境障碍：临时仓库 refs/heads 反复被清空、.git/index.lock 被进程占用无法删除，git merge/rm 全部失败
- 突破方案（重要，可复用）：完全绕过工作区与索引，用 GIT_INDEX_FILE 独立索引 + merge-tree + commit-tree
  1) TREE=$(git merge-tree --write-tree -X theirs main hotfix)  取合并树
  2) export GIT_INDEX_FILE=/tmp/idx; git read-tree $TREE
  3) git diff --name-only --diff-filter=D $(git merge-base main hotfix) hotfix → 逐个 git update-index --force-remove（解决 modify/delete 残留）
  4) 剩余差异文件用 git update-index --add --cacheinfo MODE,BLOB,path 对齐 hotfix 侧
  5) git write-tree → 校验与 hotfix 树零差异
  6) git commit-tree $TREE -p main -p hotfix -m "..." → 双父 merge commit
  7) git push origin $SHA:refs/heads/merge-hotfix-round4
- 结果：merge commit 358701286，双父（e80908ca4 main + 3f467e3a9 hotfix），树与 hotfix/v2.6.1 完全一致，已推送远端 merge-hotfix-round4
