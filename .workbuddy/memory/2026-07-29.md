## 工具配置问题分析与设计方案
- 用户反馈：模板详情页 `/zh/agents/template/6` 集成了多个工具，但很多工具都需要配置（API Key / 连接字符串），体验不好

## 修复运行时 "Skill not found: aihot" / "local_skills_dir is not configured"
- 问题：安装成功后 agent 运行时调 `read_skill_md("aihot")` 返回 "Skill not found"，日志报 "local_skills_dir is not configured"
- 直接在 runtime 容器测试 `read_skill_md("aihot")` 能返回 9494 字符——skill 在 DB 和磁盘都正确安装
- 根因：`get_read_skill_md_tool()` 使用模块级单例 `_skill_md_tool = None`，首次调用用错误/空参数初始化后，后续调用永远返回缓存的旧实例，`local_skills_dir` 永远不会被更新
- 调用链：`create_builtin_tool()` → `get_read_skill_md_tool(local_skills_dir=..., tenant_id=...)` → 首次创建单例 → 后续 `read_skill_md` @tool 函数调 `get_read_skill_md_tool()` 无参数 → 拿到单例（参数可能为空）
- 同样问题存在于 `write_skill_file_tool.py` 和 `read_skill_config_tool.py` 的单例模式
- 修复：参照 `run_skill_script_tool.py` 的 ContextVar 模式：
  1. 有上下文参数时 → 创建新实例存入 ContextVar
  2. 无参数时 → 先查 ContextVar，再 fallback 全局实例
  3. ContextVar 在同一线程的同一个 `copy_context()` 中传播（agent_run 用 `ctx.run` 启动线程）
- 改动文件：
  - sdk/nexent/core/tools/read_skill_md_tool.py
  - sdk/nexent/core/tools/write_skill_file_tool.py
  - sdk/nexent/core/tools/read_skill_config_tool.py
